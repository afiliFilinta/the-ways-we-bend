# The Ways We Bend

An interactive Three.js story about the straight lines we are taught to draw
and the curves that make us who we are.

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed by Vite.

## Production preview

```bash
npm run build
npm run preview
```

## Structure

- `index.html` — interface and story copy
- `main.js` — Three.js scene and interaction
- `style.css` — visual system and responsive layout
- `public/audio/` — local soundtrack
